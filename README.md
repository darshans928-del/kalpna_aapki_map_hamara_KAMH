
## 📂 Features
- Interactive Cesium globe visualization.
- Public gallery of recent maps.
- Archive system for older maps (on-demand access).
- Simple, lightweight, and free hosting.

## 🛠 How to Contribute
- Upload maps in **KML/KMZ/GeoJSON** format.
- Keep file sizes under 25 MB for smooth performance.
- Community uploads go into the shared Google Drive folder.
